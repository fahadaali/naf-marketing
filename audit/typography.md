## العائلات ومن أين تُحمَّل

| العائلة | التعريف | التحميل |
|---|---|---|
| `'IBM Plex Sans Arabic', 'Inter', system-ui, -apple-system, sans-serif` | `web/src/styles.css` — تعريف واحد على `body` | **لا يوجد استيراد للخط إطلاقاً** — لا `@font-face`، ولا `@import`، ولا وسم `<link>` في `web/index.html`، ولا حزمة `@fontsource` في `web/package.json` |
| `inherit` | 10 مواضع | على عناصر النموذج (`input`, `button`, `select`, `textarea`) لتوريث عائلة الجسم |

### ملاحظتان مهمّتان

1. **الخط مُعلَن ولا يُحمَّل.** `IBM Plex Sans Arabic` مذكور أولاً في المكدّس لكن لا شيء يجلبه. فعلياً يُعرض المتصفح `Inter` إن وُجد، وإلا خط النظام. هذا يعني أن المنصة **لا تعرض خط ناف اليوم** رغم ذكر اسمه.
2. العائلة نفسها التي يستخدمها السجلّ (`naf-font` = IBM Plex Sans Arabic بأوزان 400/500/600/700 مستضاف ذاتياً)، فالتحوّل هنا **إضافة تحميل** لا تغيير عائلة.

## المقاسات

**١٩ مقاساً فريداً.** لا يوجد سلّم معرَّف — المقاسات مكتوبة رقماً في كل موضع.

| المقاس | التكرار | المصدر |
|---|---|---|
| `12px` | 67 | أنماط سطرية JSX |
| `13px` | 31 | أنماط سطرية JSX |
| `14px` | 17 + 11 | CSS + JSX |
| `13px` | 12 | CSS |
| `11px` | 7 | CSS |
| `12px` | 5 | CSS |
| `15px` | 3 | CSS |
| `10px` | 2 | CSS |

### مقاسات تكرّرت أقل من ثلاث مرات (مرشّحة للانحراف)

`10px` (2) · وبقية الذيل الطويل من ١٩ قيمة — أغلبها استُخدم مرة أو مرتين في أنماط سطرية.

> `CLAUDE.md §5`: «Sizes from the scale. Never `text-[15px]`.» — وجود `15px` و`11px` و`10px` خارج أي سلّم يؤكّد غياب السلّم لا مخالفته.

## الأوزان

**٦ قيم فريدة** — ضمن نطاق ناف المسموح (400/500/600/700) مع **مخالفة واحدة**:

| الوزن | التكرار | الحالة |
|---|---|---|
| `600` | 12 (CSS) + 8 (JSX) | ✅ مسموح |
| `700` | 8 | ✅ مسموح |
| `500` | 3 (CSS) + 2 (JSX) | ✅ مسموح |
| `800` | 1 | ❌ **خارج الأوزان المسموحة** — `CLAUDE.md §5` يحصرها في 400/500/600/700 |

الوزن `400` لا يظهر صراحةً لأنه الافتراضي.

## ارتفاعات السطر

**٥ قيم فريدة**، كلها في `styles.css`:

| القيمة | التكرار | ملاحظة |
|---|---|---|
| `1.8` | 1 | على الجسم — مناسب للعربية |
| `1.6` | 1 | |
| `1.5` | 1 | |
| `1.2` | 1 | |
| `1` | 2 | ⚠️ ارتفاع سطر `1` يقصّ المحارف العربية ذات النزول والتشكيل |

> `CLAUDE.md §5`: «Do not reduce line heights. The scale is deliberately taller than a Latin-only scale because Arabic needs vertical room for ascenders, descenders and diacritics.»
>
> القيمتان `1` و`1.2` تحتاجان فحصاً بصرياً: إن كانتا على شارات/عدّادات قصيرة فقد تكونان مقبولتين، وإن كانتا على نص عربي فهما انحدار.

## الظلال — حرفياً

**١٤ تعريفاً فريداً، كلٌّ منها مستخدم مرة واحدة.** أي: لا يوجد سلّم ظلال، كل ظل كُتب لموضعه.

```
0 1px 2px hsl(var(--shadow-color) / 0.04)
0 1px 2px hsl(var(--shadow-color) / 0.1)
0 1px 2px hsl(var(--shadow-color) / 0.15)
0 4px 12px hsl(var(--primary) / 0.35)
0 4px 14px hsl(var(--shadow-color) / 0.12)
0 2px 8px hsl(var(--primary) / 0.3)
0 10px 30px hsl(var(--shadow-color) / 0.18)
0 12px 34px hsl(var(--shadow-color) / 0.2)
0 20px 50px hsl(var(--shadow-color) / 0.15), 0 1px 0 hsl(var(--foreground) / 0.02) inset
0 24px 60px hsl(var(--shadow-color) / 0.25)
0 24px 70px rgba(0,0,0,.5)
0 0 0 3px hsl(var(--ring) / 0.12)
0 0 0 3px hsl(var(--ring) / 0.15)
inset 0 0 0 1px hsl(var(--primary))
```

ملاحظتان:
- **ثلاثة ظلال بمستوى `0 1px 2px`** بشفافيات مختلفة (0.04 / 0.1 / 0.15) — متقاربات، الأرجح أنها مستوى ارتفاع واحد.
- **حلقتا تركيز** `0 0 0 3px` بشفافيتين (0.12 / 0.15) — يجب أن تكونا واحدة.
- ظل واحد فقط يستعمل قيمة خام: `rgba(0,0,0,.5)` — البقية تمرّ بالرموز المحلية.

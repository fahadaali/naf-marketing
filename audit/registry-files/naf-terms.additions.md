## ← يُضاف إلى «٤. الحالات والرسائل ← الشاشات الفارغة»

الشاشة الفارغة **دعوة للعمل** لا إعلان عن العدم. هذه خمس عشرة صياغة
طُبِّقت في `naf-marketing` على النمط المسجّل، وتُعتمد هنا.

| السياق | المعتمد |
|---|---|
| لا محتوى بعد | لم تُنشئ أي محتوى بعد. ابدأ بأول محتوى. |
| لا حملات | لم تُنشئ أي حملة بعد. ابدأ بأول حملة. |
| لا نشرات | لم تُنشئ أي نشرة بعد. ابدأ بأول نشرة. |
| لا مشتركين | لا مشتركين بعد. أضف أول مشترك أو استورد قائمة. |
| طابور اعتماد فارغ | لا محتوى بانتظار الاعتماد. الطابور فارغ. |
| لا مرفقات | لا مرفقات في هذا المحتوى. أضف أول مرفق. |
| لا نسخ سابقة | لا نسخ سابقة بعد. تُحفظ نسخة مع كل تعديل. |
| لا قوالب | لا قوالب محفوظة بعد. احفظ المحتوى الحالي كقالب. |
| لا تعليقات | لا تعليقات بعد. اضغط «جلب الآن» لسحب أحدث التعليقات. |
| لا أخبار | لا أخبار بعد. أضِف خلاصة RSS من الإعدادات ثم حدّث. |
| لا خلاصات | لا خلاصات بعد. أضِف أول خلاصة RSS. |
| لا حسابات مربوطة | لا حسابات مربوطة بعد. اربط حساباً من لوحة المزوّد. |
| لا حسابات فيديو | لا حسابات فيديو مربوطة. اربط يوتيوب أو تيك توك من الإعدادات. |
| لا سجلّ تدقيق | لا نشاط مسجّل في هذه المدة. وسّع النطاق الزمني. |
| لا محتوى مجدول | لا محتوى مجدول لعرضه على المخطّط الزمني. جدوِل أول محتوى. |

**النمط المستخلص، لصياغة ما يستجدّ:**
*نفي بلا «توجد»* + *«بعد.»* + *فعل أمر يبدأ العمل.*
«لا مشتركين بعد. أضف أول مشترك.» لا «لا يوجد مشتركون».

## ← يُضاف إلى «٥. التنسيق ← كل رقم وتاريخ ومبلغ»

**في JSX** استعمل `<bdi>`.
**في السلاسل الخام** — رسائل `confirm` ونصوص الحالة والتنبيهات — استعمل
`isolate()` من `naf-format`، فـ`<bdi>` لا يصلح فيها.

بدون الثانية تبقى كل رسالة فيها رقم منحرفة، وهي أكثر من نصف الرسائل عملياً.
في `naf-marketing` وحدها كانت ١٩ رسالة.

**صيغة الشهر والسنة** لعناوين التقويم ومنتقي التاريخ: `2026/07` — مشتقّة من
الصيغة الميلادية المسجّلة بحذف اليوم. **أسماء الأشهر العربية ليست صيغة
مسجّلة** ولا تُستعمل لعرض قيمة تاريخ؛ تُستعمل تسميةً في شبكة اختيار الشهر
فقط، وهذا فرق حقيقي لا لفظي.

**صيغة التاريخ والوقت معاً:** `2026/07/26 14:30`.

## ← بند يحتاج قرارك قبل التسجيل

`بانتظار المراجعة` و`بانتظار الاعتماد` المسجّلتان طابقتا مرحلتَي الاعتماد
في `naf-marketing` بالضبط وطُبِّقتا هناك. **لكنهما تُسقطان ذكر الجهة** —
كانتا «بانتظار مراجعة التسويق» و«بانتظار اعتماد المدير العام».

إن كان تمييز الجهة مطلوباً في منصة، فالصيغتان الأطول تحتاجان تسجيلاً
مستقلاً. لم أسجّلهما لأن ذلك قرارك لا استنتاجي.
